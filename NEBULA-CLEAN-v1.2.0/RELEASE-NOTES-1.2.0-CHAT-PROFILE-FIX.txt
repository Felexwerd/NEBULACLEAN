NEBULA CLEAN 1.2.0 — CHAT LAYOUT / PROFILE / SERVER MIGRATION FIX

Client changes:
- Replaced DockPanel-based chat composer with a Grid so the message field gets the available width and buttons remain correctly sized.
- Replaced the chat header DockPanel with a Grid so the Refresh button no longer stretches across the header.
- Profile page now renders the selected avatar image instead of showing only a dot/check mark.
- Chat avatars are decoded after WPF bindings are applied.
- Chat rows show prefix (fallback "free") and account role (FREE/ADMIN).
- Sending text/photo/voice saves the current profile first so prefix/avatar are reflected in chat.
- Voice upload is capped to avoid oversized base64 payloads.

Server changes:
- Startup migration adds chat_messages.message_type to existing SQLite databases made by older versions. Without this migration, chat GET/POST can fail with "no such column: message_type".
- Avatar size limit adjusted to accommodate base64-encoded 2 MB images.

IMPORTANT:
- The updated NebulaServer must be deployed to the hosting provider for the database migration and API fixes to take effect.
- This archive has not been compiled or run on Windows in this environment. Build/test on Windows and inspect the launcher log if any errors remain.

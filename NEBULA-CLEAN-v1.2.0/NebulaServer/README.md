# NEBULA CLEAN — комплект для размещения API и веб-панель администратора

В комплекте:
- `NebulaServer` — ASP.NET Core API для общих аккаунтов, подписок, промокодов и проверки версии.
- `NebulaServer/wwwroot/index.html` — веб-панель администратора, открывается на корневом адресе API.
- `NebulaServer/Dockerfile` и `render.yaml` — шаблон развертывания на Render.
- `NebulaClean-Fixed` — Windows WPF-клиент.

## Быстрый бесплатный запуск на Render

1. Распакуйте ZIP.
2. Создайте репозиторий на GitHub и загрузите в него папки `NebulaServer` и `NebulaClean-Fixed` вместе с файлами. Не загружайте `client_secrets.json`, пароли, токены или другие секреты.
3. В Render создайте новый Web Service из этого репозитория. Выберите Docker; укажите Dockerfile `NebulaServer/Dockerfile`, контекст сборки `NebulaServer`, если интерфейс Render просит его отдельно. Можно использовать `render.yaml`.
4. В Environment добавьте:
   - `NEBULA_ADMIN_EMAIL` = почта администратора;
   - `NEBULA_ADMIN_PASSWORD` = новый уникальный пароль администратора (не используйте пароль от почты);
   - `NEBULA_DB_PATH` = `/app/nebula.db` (значение по умолчанию в шаблоне).
5. Дождитесь успешного Deploy. Проверьте `https://ВАШ-СЕРВИС.onrender.com/health` — ожидается JSON со статусом `ok`.
6. Откройте `https://ВАШ-СЕРВИС.onrender.com/`. Войдите с админской почтой и паролем. Панель позволяет менять версии, ссылку обновления и сообщение, создавать/удалять промокоды, выдавать пользователям планы Free/Promo.
7. В Windows-клиенте откройте `NebulaClean-Fixed/appsettings.json` и замените `ApiBaseUrl` на адрес своего сервиса с завершающим `/`, например `https://ВАШ-СЕРВИС.onrender.com/`. Пересоберите/запустите клиент. Всем пользователям приложения нужно задать один и тот же API URL.

## Важное ограничение бесплатного размещения

Бесплатный веб-сервис Render может засыпать при простое, а локальная файловая система контейнера не является постоянным хранилищем. В текущей версии API используется SQLite-файл. Поэтому **не считайте эту конфигурацию надёжным постоянным хранилищем**: при перезапуске/повторном развертывании база может потеряться, включая аккаунты и промокоды. Бесплатный тариф не гарантирует постоянный диск. Для настоящего общего сервиса сначала подключите постоянную базу данных/хранилище и мигрируйте API на него либо используйте хостинг с постоянным диском. Не раздавайте приложение реальным пользователям, пока не проверили сохранность базы после повторного развертывания.

## Google-вход

Клиенту нужен OAuth client JSON из Google Cloud Console. Следуйте инструкциям в `NebulaClean-Fixed/README.md`; не публикуйте секреты в GitHub. Google-вход работает только после настройки OAuth.

## Безопасность

- Используйте уникальный пароль администратора и храните его только в секретных переменных хостинга.
- Если пароль уже отправляли в чат или публиковали, смените его.
- Панель администратора защищена серверной ролью, но это не заменяет HTTPS, резервные копии, ограничение частоты запросов, аудит и проверку безопасности перед публичным запуском.
- Не устанавливайте минимальную версию выше текущей, пока не загрузили рабочий файл обновления и не проверили ссылку.
- Этот проект подготовлен для дальнейшего развертывания, но здесь он не был собран, опубликован или проверен на реальном хостинге.

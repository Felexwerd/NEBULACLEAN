# NEBULA CLEAN 1.2.0 — Windows

## Что добавлено
- Выбор доступного фиксированного диска в интерфейсе; кольцо свободного места вращается.
- Для не системного диска показываются только стандартные временные папки `X:\Temp` и `X:\Windows\Temp`, если они существуют. Программа не удаляет всё содержимое выбранного диска.
- Новые разделы «Чат» и «Профиль».
- Чат использует API на сервере NEBULA; сообщения общие для авторизованных пользователей, добавлены быстрые эмодзи.
- Префикс и аватар профиля, синхронизация профиля и сообщений через сервер.
- Выбор одного из 4 языков: English (по умолчанию), русский, беларуская, українська.
- Исправлена инициализация входа администратора: при запуске сервера заданный `NEBULA_ADMIN_PASSWORD` обновляет пароль существующего admin-аккаунта с тем же email.
- Версия приложения повышена до 1.2.0.

## Важные условия
1. Чтобы общий чат и синхронизация профиля работали, обновите `NebulaServer` на своём Render-сервисе кодом из этого архива. После публикации проверьте `/health`.
2. Выбор аватара и профиль доступны локально даже без сервера, но общий чат требует входа и работающего API.
3. В этой сборке запись голосовых сообщений пока не реализована. Она не имитируется кнопкой, которая ничего не делает.
4. Полный перевод всех надписей ещё не завершён: язык по умолчанию и навигационные заголовки переключаются, часть описаний в страницах пока остаётся на русском.
5. В этой среде не установлен .NET SDK/Windows-компилятор, поэтому проект не был собран и прогнан в Windows здесь. Workflow ниже собирает Windows x64 приложение на GitHub Actions.

## Как получить готовую Windows-сборку
1. Скопируйте содержимое архива в корень своего репозитория GitHub.
2. Откройте **Actions** → **Build NEBULA CLEAN 1.2.0 Windows** → **Run workflow**.
3. После успешной сборки откройте запуск workflow и скачайте артефакт `NEBULA-CLEAN-v1.2.0-Windows-x64`.

## Безопасность очистки
На не системных дисках приложение работает только с обнаруженными стандартными временными папками. Если такие папки не найдены, очистка ничего не удалит. Перед удалением требуется подтверждение.
